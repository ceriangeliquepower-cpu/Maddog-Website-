# Internal link targets by topic

Use these as the default choice when picking the 2+ internal links required in every blog post (SKILL.md §4). Pick whichever 2 are most genuinely relevant to the post's actual topic — don't force both just to hit the count if only one truly fits, and add a third from elsewhere on the site if neither of these two fits well.

| BJJ (kids) | `training-kids-bjj-ballito.html`, `training-bjj-ballito.html` |

| Personal Training | `training-personal-training-ballito.html`, `coaches.html` |
